# Fishing Memory App

釣りサークル公式ウェブサイトの開発用リポジトリです。

## 開発環境

このプロジェクトは Vite + React で作成しています。

## ローカルで起動する手順

```bash
npm install
npm run dev
```

表示されたURLをブラウザで開くと、開発中のサイトを確認できます。

## 主なファイル

```txt
index.html        ブラウザが最初に読むHTML
src/main.jsx      Reactを起動する入口
src/App.jsx       画面の中身
src/App.css       デザイン
package.json      使用するライブラリや起動コマンド
```
